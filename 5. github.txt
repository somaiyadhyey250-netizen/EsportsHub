HOW TO RUN / VIEW THE PROJECT:
------------------------------------------------------------------------
Because the project uses modern ES6 modules (import/export), it should be
served through a local web server:

Method 1 (Recommended - VS Code Live Server):
1. Open this folder in VS Code.
2. Right click on "Client/index.html" -> Select "Open with Live Server".
3. Right click on "Admin/dashboard.html" -> Select "Open with Live Server".

Method 2 (Python Simple HTTP Server):
1. Open terminal/PowerShell in this folder.
2. Run: python -m http.server 5500
3. In your browser, open:
   - Client: http://127.0.0.1:5500/Client/index.html
   - Admin : http://127.0.0.1:5500/Admin/dashboard.html

Method 3 (Node.js):
1. In terminal: npx serve .
2. Open the displayed URL and navigate into Client or Admin.
